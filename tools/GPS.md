# GPS

- `.gps <x> <z>` — направление по горизонтали; высота не учитывается.
- `.gps <x> <y> <z>` — расстояние с учётом высоты, разница Y рядом со стрелкой.
- `.gps waypoint <name>` — направление к точке Waypoints. Имена с пробелами поддерживаются.
- `.gps off` — остановка.
- `.gps voice on` / `.gps voice off` — озвучка. Выбор хранится в `gps.json` в папке настроек клиента.
- `.gps voice alice` / `.gps voice oksana` — выбрать голос и включить озвучку.

Стрелка поворачивается относительно камеры. Один блок считается одним метром.
GPS показывает прямое направление к цели, обход препятствий не рассчитывает.
В области action bar используется SF Pro; если сервер показывает своё сообщение,
GPS перемещается выше него. При F1 и в чистом захвате GPS скрыт.
При прибытии маршрут завершается. При смене мира/сервера или отключении он сбрасывается.

## Голосовые подсказки

В клиент включены **Алиса** (по умолчанию) и **Оксана** из предоставленного архива
`pasting/yandex_navigator_all_voices_250421.scs`. По шесть фраз на голос: начало движения,
прямо, налево, направо, разворот и прибытие. Дополнительный ресурс-пак не нужен.

Источник пакета FirryFinch **Yandex.Navigator — All voices**:
https://steamcommunity.com/sharedfiles/filedetails/?id=1937471331
Автор указывает источником звуки из APK Яндекс Навигатора.
Это исходные записи из архива, преобразованные из FMOD FSB5 в OGG Vorbis.
Их соответствие исходным фразам и SHA-256 записаны в `assets/pizzadlc/sounds/gps/source.json`.

Повторный импорт из SCS: `python tools/import_gps_yandex.py`. Для импорта используются
декодер vgmstream из официального проекта https://github.com/vgmstream/vgmstream
и FFmpeg; пути можно указать параметрами `--decoder` и `--ffmpeg`.
Эти инструменты нужны только при подготовке ресурсов и не включаются в клиент.

## Другие голосовые ресурс-паки

Чтобы заменить встроенные записи своими, подготовь отдельные OGG Vorbis:

| Файл | Подсказка |
| --- | --- |
| `straight.ogg` | Продолжайте движение прямо |
| `left.ogg` | Поверните налево |
| `right.ogg` | Поверните направо |
| `uturn.ogg` | Развернитесь |
| `arrived.ogg` | Вы прибыли |
| `start.ogg` | Начало движения (необязательно) |

Собрать ресурс-пак из папки с этими файлами:

```powershell
python tools/pack_gps_voice.py 'C:\путь\к\подсказкам'
```

Включи созданный `GPS-Voice.zip` в ресурс-паках Minecraft, затем `.gps voice on`.
Звуки воспроизводятся локально через Minecraft, без запросов к сервисам Яндекса.
Подсказка направления требует устойчивого поворота камеры минимум секунду;
повтор возможен через 6 секунд при смене направления или 15 секунд для прежнего,
только после перемещения минимум на 3 блока. Файлы не накладываются друг на друга.
